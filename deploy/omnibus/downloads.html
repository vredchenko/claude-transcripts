Claude Transcripts @VERSION@

Served by this instance. Each file has a .sha256 next to it.

CLI

Linux x64claude-transcripts-linux-x64
Linux arm64claude-transcripts-linux-arm64
macOS x64claude-transcripts-darwin-x64
macOS arm64claude-transcripts-darwin-arm64
BASE=http://127.0.0.1:7650/downloads   # this page's address
curl -fsSLO "$BASE/claude-transcripts-linux-x64"
curl -fsSL "$BASE/claude-transcripts-linux-x64.sha256" | sha256sum -c -
install -m 755 claude-transcripts-linux-x64 ~/.local/bin/claude-transcripts

Claude Code plugin

claude-transcripts-plugin.tar.gz — a local plugin marketplace.

curl -fsSL "$BASE/claude-transcripts-plugin.tar.gz" | tar -xz -C ~/.claude
claude plugin marketplace add ~/.claude/claude-transcripts-plugin
claude plugin install claude-transcripts@claude-transcripts

The plugin hands every hook event to the CLI above, and needs Bun on PATH.
