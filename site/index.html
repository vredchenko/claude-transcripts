Self-hosted history for
Claude Code sessions

A Claude Code hook logs every session — events, an end-of-session summary, and the full transcript — through a web API into your own CouchDB + S3 storage. The same API serves it back; a web UI, a CLI, and AI agents read it. Nothing leaves your network.

Yours, entirely

Runs on your own infrastructure — CouchDB + S3-compatible storage. No third-party service, no data leaving your network.

What is stored where →

Full transcripts

Every session is captured: per-event records, a summary with token + tool usage, and a byte-faithful copy of the full transcript. A session that crashes before it ends is finalised later from what was recorded.

What you see while it records →

Searchable

Full-text search over every session and every turn, with filters by project, host and model — from the web UI, the CLI or the API.

Web UI · CLI · API

Browse in the web UI, script with the CLI, or read the OpenAPI-typed web API directly — the single gateway to everything.

Agent-readable

The corpus is built to be consumed by agents too. The plugin ships skills that let Claude search your history before re-deriving past work — a foundation for recall and analytics.

How recall works →

In step with Claude Code

Every session checks the running Claude Code's hook events and payloads against what this build was made for, and says in one line whether they match — or what changed.
